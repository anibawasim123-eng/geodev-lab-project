# Healthcare Accessibility in Lahore

## Project Question

Which areas of Lahore are more than 5 km from a mapped healthcare facility?

## Study Area

The study area is Lahore District, Punjab, Pakistan.

## Why This Matters

Access to healthcare is an important spatial issue because healthcare facilities are not distributed evenly across urban areas. This project will identify areas of Lahore that are more than 5 km from mapped healthcare facilities.

The results can help highlight areas where healthcare accessibility may be relatively limited and provide a starting point for further spatial analysis and web mapping.

## Datasets

### 1. Lahore District Boundary

**Dataset:** Pakistan administrative boundaries

**Source:** DIVA-GIS

**Source link:** https://www.diva-gis.org/gdata

The Lahore District boundary will be extracted from the Pakistan administrative boundary shapefile.

### 2. Healthcare Facilities

**Dataset:** Hospitals/healthcare facilities in Lahore

**Source:** OpenStreetMap contributors

**Source link:** https://www.openstreetmap.org/

The healthcare facility data was collected using the QuickOSM plugin in QGIS.

The initial hospital query returned 185 features.

**License:** https://www.openstreetmap.org/copyright

## Planned Analysis

The healthcare facilities will be mapped within the Lahore study area. A 5 km distance analysis will then be used to identify areas that are more than 5 km from mapped healthcare facilities.

The project will later be developed into an interactive WebGIS application showing healthcare accessibility across Lahore.

## Tools
